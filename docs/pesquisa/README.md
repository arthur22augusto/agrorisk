1. Resumo executivo (5–10 linhas, com números).
2. Corpo com tabelas; **toda afirmação factual com link**. O que não foi verificado aparece marcado como "não verificado".
3. **Oportunidades de inovação para o AgroRisk** — cada uma com evidência, fonte, por que os concorrentes não fazem, esforço estimado (P/M/G).
4. **Riscos e contra-evidências.**
